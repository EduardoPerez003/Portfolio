PORTFOLIO DE EDUARDO PÉREZ CARRILLO

Cómo abrirlo:
1. Descomprime la carpeta/archivo ZIP.
2. Abre index.html en un navegador moderno.

Contenido:
- index.html: estructura y contenido de la web.
- styles.css: diseño adaptable, colores corporativos y modo claro/oscuro.
- script.js: selector de idioma (español, inglés y francés), tema y menú móvil.
- assets/eduardo.png: fotografía de perfil proporcionada.
- assets/curriculum.pdf: currículum proporcionado.
- assets/cv-europass-eduardo-perez.pdf: CV Europass proporcionado.

Notas:
- El vídeo de YouTube se incrusta en la sección de voluntariado y requiere conexión a Internet.
- Los enlaces externos abren en otra pestaña.
- Para publicar el portfolio, puedes subir la carpeta a GitHub Pages, Netlify o un hosting web.
- No se ha inventado una lista de proyectos técnicos: el apartado enlaza al perfil de GitHub para mostrar los repositorios reales.
